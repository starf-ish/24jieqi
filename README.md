# 二十四节气研究与发扬

一个以「二十四节气」为主题的中学地理探究专题网站，采用国风水墨视觉风格，单文件（`index.html`）打包，双击即可打开，也可直接部署到 GitHub Pages。

## 网站简介

本网站围绕二十四节气展开，从时间体系的整体面貌、具体节气详解，到新加坡视角下的气候对照、传统养生智慧等多个角度，尝试重新走近这套流传千年的时间知识体系。全站内容目前均为占位框架，用于搭建整体结构与交互，后续可逐步填入真实研究内容。

## 主要功能

### 首页
- **顶部日期栏**：实时显示公历日期、星期、农历月日与当前节气（例如「2026-07-29　星期三　农历六月十六　大暑」），节气计算基于离线天文近似公式，无需联网也可正常显示。
- **节气转盘**：一个持续缓慢自转的二十四节气圆盘，当前节气会自动高亮发光；转盘上每一个节气文字都可以点击，进入该节气的专属页面。
- **四时之序**：春、夏、秋、冬四张卡片，点击进入对应季节的独立页面。
- **Explore 专题区**：节气大观园、新加坡气候分析、养生小建议、拓展阅读、参考文献、节气总说、节气简介，共 7 个专题入口。
- **季节主题色**：页面配色会根据当前实际节气所属的季节（春/夏/秋/冬）自动切换色调。

### 节气大观园
一个二级枢纽页面，内含 7 个子入口：节气歌、二十四番花信风、非遗文化、七十二物候、经典习俗、金句、科学分析，每个都可再点开独立页面。

### 24 个节气详情页
点击转盘上任意一个节气（如「立春」「芒种」「大暑」），会打开该节气专属的详情页，页面内还有 4 个完全独立的按钮：
- 节气诗词
- 节气详解
- 节气谚语
- 节气推荐活动

**每个节气的这 4 个按钮都指向各自独立的页面**——立春的「节气诗词」和芒种的「节气诗词」是两个不同的页面，共计 24 × 4 = 96 个独立子页面，互不共用内容。

### 页面间导航
- 每个页面顶部都有「返回首页」或「返回上一级」的链接。
- 同组页面之间（例如同一节气的 4 个按钮、或 Explore 下的 7 个专题）设有可横向滚动的快速跳转标签栏，方便来回切换。
- 使用浏览器地址栏的 `#` 锚点做路由（例如 `#term-lichun`、`#zongshuo`），支持浏览器前进/后退按钮，也可以直接分享指向某个具体页面的链接。

### 视觉风格
- 宣纸底色、墨黑文字、朱红印章色为主色调的国风水墨配色。
- 页面顶部与底部为回纹（传统回字纹样）装饰边。
- 页面四周有双线画框（外层朱红细线 + 内层金色细线），呼应传统裱画。
- 各专题页大标题采用双线镶边横幅，内容占位框带金色内嵌细线。
- 页面底部固定一道极淡的山峦剪影。
- 所有按钮统一使用色条替代图标，风格更克制统一。

## 技术说明

- **纯前端单文件**：全部 HTML、CSS、JavaScript 打包在一个 `index.html` 文件中，无需安装任何依赖或构建工具，双击即可在浏览器中运行。
- **路由方式**：基于 URL Hash 的单页应用（SPA）路由，页面切换在同一个文件内完成，不会实际跳转到别的文件。
- **动画效果**：滚动淡入、卡片悬浮、页面切换过渡（使用 View Transitions API，Chrome / Edge 效果最佳）。
- **外部依赖**：仅通过 CDN 异步加载 [lunar-javascript](https://github.com/6tail/lunar-javascript) 用于农历日期换算；该库若加载失败或无网络，节气与日期显示仍可正常工作（离线算法兜底），只是农历月日部分会暂时不显示。

## 如何使用

### 本地打开
直接双击 `index.html`，用浏览器打开即可，无需服务器。

### 部署到 GitHub Pages
1. 新建一个 GitHub 仓库（仓库名会成为访问路径的一部分）。
2. 将本文件重命名为 `index.html` 后上传到仓库根目录。
3. 进入仓库 Settings → Pages，Source 选择「Deploy from a branch」，分支选 `main`，目录选 `/(root)`，保存。
4. 等待一两分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问。
